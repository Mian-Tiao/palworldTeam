## 已確認的業務規則(1.0 純被動相對輸出模型,2026-08-13,P-12)

| 項目 | 內容 |
|------|------|
| 計算定位 | 用來比較「同等級、同目標下哪個配隊更能提高固定帕魯輸出」的相對分數,不宣稱是實機精確傷害;取代 2026-07-16 的舊絕對傷害公式 |
| 單次分數 | `0.8 × sqrt(等級 + 1) × 技能威力 × 攻擊值 ÷ 參考敵方防禦 × 克制 × STAB`;0.8 為 1.0 帕魯技能共通傷害率 |
| 攻擊值 | `FLOOR(100 + 攻擊種族值 × 0.075 × 等級)`;統一基準:個體值 0、無詞條、無濃縮/魂強化 |
| 攻擊種族值選用 | 所有主動技能統一採 `shot_attack_stat`(遊戲顯示攻擊);category 僅表示招式行為 |
| 屬性克制 | 克制 1.50×、抵抗 0.66×;雙屬性逐項相乘(雙克制 2.25×);同屬性技能加成(STAB)1.20× |
| 敵方防禦 | 指定頭目:以其資料計 `50 + 防禦種族值 × 0.075 × 等級`;未指定目標:防禦視為常數(不影響排名) |
| 技能輸出 | 每帕魯自「習得等級 ≤ 所選等級」的技能中,取每秒分數(單次分數÷冷卻)最高的 3 個,總輸出為三者之和;多段命中、動畫時間與命中率尚未建模 |
