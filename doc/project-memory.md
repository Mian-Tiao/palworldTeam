## 已確認的業務規則(傷害公式,2026-07-16,Q-6/Q-D3 結案)

| 項目 | 內容 |
|------|------|
| 傷害公式 | `傷害 = 1.1 × ((1.5×等級 + 20) × 技能威力 × 攻擊值 ÷ 敵方防禦) ÷ 15`(社群共識版) |
| 攻擊值 | `FLOOR(100 + 攻擊種族值 × 0.075 × 等級)`;統一基準:個體值 0、無詞條、無濃縮/魂強化 |
| 攻擊種族值選用 | 依技能 category(Shot/Melee)採用 shot_attack 或 melee_attack |
| 屬性克制 | 克制 2×、被克 0.5×;雙屬性相乘(最高 4×、最低 0.25×);同屬性技能加成(STAB)1.2× |
| 敵方防禦 | 指定頭目:以其資料計 `50 + 防禦種族值 × 0.075 × 等級`;未指定目標:防禦視為常數(不影響排名) |
| 技能輸出 | 每帕魯自「習得等級 ≤ 所選等級」的技能中,取加權 DPS(威力÷冷卻×倍率)最高的 3 個(遊戲裝備上限),總輸出為三者之和 |
| 夥伴技能 | 僅 team_buff 型;同類加成相加後乘上攻擊值;buff_element 有值時僅對含該屬性的帕魯生效;player_attack 型加成玩家武器輸出,不影響帕魯排名,不納入(P-2 實作時明確化) |
| 夥伴技能星級(P-8b,2026-07-18) | 夥伴技能加成隨專注(濃縮)星級 0~4 提升;使用者於前端選星級(全隊套用,預設滿星 4)。逐星值自遊戲被動表各專注階(PassiveSkills[0..4])萃取,存 partner_skill_buff_tier | 使用者以練滿(滿星)的印象檢視,0 星基準與其認知差 5 倍;做成可選最準 | convert_raw、import_data、partner_skill_buff_tier、API star_level、前端星級選擇器 |
| 疊層型夥伴技能(P-8b) | 如波魯傑克斯(命中疊攻,上限 30 層)、焰煌(擊殺疊攻,上限 5 層):以「滿疊理論值」計 = 每層 % × 最大層數(對應遊戲滿星 150% 等描述)。上限自描述「最多可累積 N 層」解析。**取代 2026-07-18 稍早的「維持係數 0.5」估法**——改為明確的滿疊上限並於前端標註「滿疊N層理論值」,實戰維持度會低於此 | 使用者記得的是滿疊上限值(150%);明確標註比任意打折更透明 | import_data、前端 BuffChips |
| 隨機浮動 | ±10% 取期望值,不納入 |
| 2026-07-16 | 第一階段做「最大傷害隊伍篩選」,第二階段才做「打工配置」 | 需求訪談確認的優先順序 | todo 排序、開發範圍 |
